# IDEA - Web3 Services Marketplace

A decentralized marketplace built on MultiversX, connecting clients with Web3 developers, artists, and blockchain experts.

## Features
- Browse and create gigs for Web3 services
- Post and manage client requests
- Secure authentication and transaction signing via MultiversX
- User profiles and order management

## Requirements
- Node.js version 16.20.0+
- Yarn or npm (Yarn recommended)

## Getting Started

### Installation
