# MX Builder - No-code MultiversX DApp Builder

A powerful no-code platform for creating branded staking and presale sites on the MultiversX blockchain.

## Features
- Visual drag-and-drop builder for Web3 applications
- Pre-built templates for staking and presale sites
- MultiversX wallet integration (xPortal, Web Wallet, Ledger)
- Smart contract parameter configuration
- Real-time preview and customization
- One-click deployment to IPFS

## Requirements
- Node.js version 16.20.0+
- Yarn or npm (Yarn recommended)

## Getting Started

### Installation
Navigate to the project folder and run:
```bash
yarn install
```

### Development
```bash
yarn dev
```

### Build for Production
```bash
yarn build
```

## Templates

### Staking Template
- Customizable APY rates
- Token staking/unstaking functionality
- Real-time rewards calculation
- Smart contract integration

### Presale Template
- Token sale configuration
- Whitelist management
- Contribution tracking
- Automatic token distribution

## Smart Contract Integration

The builder supports integration with MultiversX smart contracts:
- Staking contracts for yield farming
- Presale contracts for token launches
- Custom contract parameter configuration
- Automatic transaction handling

## Deployment

Sites built with MX Builder can be deployed to:
- IPFS for decentralized hosting
- Traditional web hosting
- MultiversX hosting solutions
